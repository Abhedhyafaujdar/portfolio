Ekdanta — AI-Powered Digital Cybercrime Investigator (MVP)

Role: Backend Architect and Full-Stack Integrator • Note: Research & engineering MVP (not a deployed law-enforcement product).

Architected a FastAPI backend and React/Vite/TypeScript investigative interface that ingests unstructured .docx cybercrime case files, filters out physical red herrings via structured OpenAI-compatible LLM system prompts, and enforces Pydantic validation for node-graph visualization.

  • • Architected a FastAPI backend that ingests unstructured cybercrime case files (.docx with system logs, physical access records, and network events) for automated forensic analysis.
  • • Integrated an LLM through an OpenAI-compatible API with strict system prompts that reject red herrings (e.g., physical decoys vs. real digital compromise) and extract suspects, devices, IPs, and credentials into an attack chain.
  • • Enforced a Pydantic schema (nodes, edges, timeline, executive report) on LLM output for consistent, validated JSON, and built HTTPX fallbacks and error handling for rate limits, authentication errors, and schema validation failures.
  • • Connected a React/Vite/TypeScript frontend using asynchronous REST calls and FormData file uploads, passing graph state to dashboard components for a working end-to-end node-graph visualization.
Python FastAPI Pydantic HTTPX React Vite TypeScript

SentinelVoice — Multimodal AI-Generated Media Screening Tool

Built end-to-end at the Brewing Codes 4.0 Hackathon (2026): a Flask REST API and web UI that screens audio, images, sampled video frames (up to 8 frames), and text documents across 25+ file formats (100 MB upload limit) for indicators of AI-generated media, returning a verdict, confidence score, and plain-English explanation.

  • • Built end-to-end in a hackathon a Flask REST API and web UI that screens audio, images, sampled video frames, and text documents for signs of AI-generated content, returning a verdict, confidence score, and plain-English explanation.
  • • Engineered a CPU-based voice-clone detector by extracting Librosa features (MFCCs, pitch, jitter) and training a scikit-learn classifier, with scripted data generation, training, and serving steps.
  • • Integrated pretrained Hugging Face models for image and text detection, added video screening by extracting up to 8 frames for image analysis, and supported 25+ file formats (including PDF and DOCX) with a 100 MB upload limit.
  • • Documented model limitations and licensing constraints in the README, such as the non-commercial image model and English-only text detector (screening signals are probabilistic, not infallible).
